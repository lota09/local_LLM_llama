## 한 줄 요약

```
토큰시간 = 커널항 + 접근행수 × 미스율 × 폴트지연
           18.2~21.0 ms   16(고정)   0~100%   209 µs (NVMe) ~ 7,280 µs (HDD)
           빌드·양자화     아키텍처    RAM      장치·경합
```

- 디스크에서 끌어오는 양은 **토큰당 최대 64 KB = 초당 2.7 MB**. 전문가 가중치를 같은 식으로
  다루면 93 GB/s 가 필요하다 — **34,000배** 차이.
- 웜(폴트 0) 47.9 tok/s · 미스 100% 41.9 tok/s → **페이징 비용 상한 12~15%**.
- **장치는 폴트가 발생할 때만 보인다.** 테이블을 2009년 HDD 로 옮겨도 폴트 0 이면 48.8 tok/s 로 같다.
- 갈리는 것은 장치 종류가 아니라 **폴트 지연**이다. 같은 NVMe 를 경합으로 6,824 µs 까지
  늦추면 HDD(7,237 µs)와 같은 값이 나온다.
